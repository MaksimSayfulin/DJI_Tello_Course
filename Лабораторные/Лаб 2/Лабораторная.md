Задание: научить компьютер находить предметы на фотографии,
например, красное яблоко, синюю ручку или зелёный лист.
1. Как компьютер видит фотографию?

Для человека фотография - это изображение предметов. Для компьютера - таблица из крошечных точек, которые называются пикселями.

У каждого пикселя есть цвет. В обычной цветной картинке он складывается
из трёх составляющих:

    R (Red) --- красный;
    G (Green) --- зелёный;
    B (Blue) --- синий.

Например, красный цвет можно записать так: (255, 0, 0).

Число 0 означает, что цвета нет, а 255 - что его очень много. Смешивая
красный, зелёный и синий, можно получить множество цветов.

Запомните: изображение - это большая таблица пикселей, а цвет
пикселя - набор чисел.
Мини-эксперимент

Представим три фонарика: красный, зелёный и синий. Что получится, если
включить все три на полную яркость? Правильно - белый свет!
2. Знакомимся с OpenCV

OpenCV - библиотека Python, которая помогает компьютеру работать с
изображениями и видео.

С её помощью можно:

    открывать и сохранять фотографии;
    менять размер и цвет изображения;
    размывать и улучшать картинки;
    искать предметы определённого цвета;
    находить края и контуры;
    работать с веб-камерой.

Установка

Открой терминал и выполни:

python -m pip install opencv-python numpy

Для заданий нам понадобятся две библиотеки:

import cv2
import numpy as np

cv2 - это OpenCV, а numpy помогает работать с массивами чисел, из
которых состоят изображения.
Открываем первую фотографию

Положи фотографию photo.jpg рядом с Python-файлом и запусти:

import cv2

image = cv2.imread("photo.jpg")

if image is None:
    print("Не удалось открыть фото. Проверь имя и путь к файлу.")
else:
    cv2.imshow("My photo", image)
    cv2.waitKey(0)
    cv2.destroyAllWindows()

Что здесь происходит?

    1.
    cv2.imread() читает фотографию.
    2.
    cv2.imshow() показывает её в отдельном окне.
    3.
    cv2.waitKey(0) ждёт нажатия клавиши.
    4.
    cv2.destroyAllWindows() закрывает окна OpenCV.

Запомни: если imread() не нашёл файл, он вернёт None. Поэтому
полезно проверять, удалось ли открыть изображение.
3. RGB и BGR: почему цвета перепутались?

Есть маленькая хитрость: многие программы записывают цвета как RGB, а
OpenCV при чтении фотографии обычно использует порядок BGR.

То есть OpenCV сначала хранит синий канал, затем зелёный, затем красный.

Представь, что у детектива цветные карточки лежат не в том порядке.
Чтобы правильно прочитать цвет, нужно поменять местами красный и синий
каналы.

image_bgr = cv2.imread("photo.jpg")

# Переводим BGR в RGB
image_rgb = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2RGB)

# А если исходная картинка уже в RGB,
# можно перевести её в BGR:
image_bgr_again = cv2.cvtColor(image_rgb, cv2.COLOR_RGB2BGR)

Важно: cv2.imread() уже возвращает BGR. Не нужно переводить его в
BGR ещё раз.
4. Изображение - это таблица

OpenCV хранит изображение как массив чисел.

Узнаем размер фотографии:

image = cv2.imread("photo.jpg")

height, width, channels = image.shape

print("Высота:", height)
print("Ширина:", width)
print("Количество каналов:", channels)

У цветной фотографии обычно три канала.

    height --- высота в пикселях;
    width --- ширина в пикселях;
    channels --- количество цветовых каналов.

Что такое shape?

shape — это свойство изображения, которое рассказывает нам, какого размера фотография и из скольких каналов она состоит.

У фотографии есть:

    количество строк — высота фотографии;
    количество столбцов — ширина фотографии;
    количество каналов — сколько чисел хранится для описания цвета каждого пикселя.

Когда мы пишем:

image.shape

Python возвращает три числа, например:

(600, 800, 3)

Это означает:

    600 — высота фотографии (600 пикселей);
    800 — ширина фотографии (800 пикселей);
    3 — три цветовых канала (B, G, R).

Важно запомнить: OpenCV записывает размеры в порядке:
(высота, ширина, количество каналов)

А не наоборот!

shape можно представить как паспорт фотографии: он рассказывает компьютеру, какого размера изображение и как оно устроено.
Координаты

Представь шахматную доску. У каждой клетки есть своё место.

В изображении тоже есть координаты:

    x --- положение слева направо;
    y --- положение сверху вниз.

Начало координат находится в левом верхнем углу.

Можно обратиться к пикселю:

pixel = image[50, 100]
print(pixel)

Здесь сначала указывается строка (`y`), затем столбец (`x`). Поэтому
image[50, 100] --- пиксель с координатами x=100, y=50.
Меняем размер фотографии

small = cv2.resize(image, (400, 300))

cv2.imshow("Small photo", small)
cv2.waitKey(0)
cv2.destroyAllWindows()

В resize сначала указывают ширину, затем высоту.
Сохраняем результат

cv2.imwrite("result.jpg", small)

Теперь рядом с программой появится файл result.jpg.

6. HSV - цветовой детектив

Теперь самое интересное!

До этого мы записывали цвет через красный, зелёный и синий. Но
компьютерному детективу бывает удобнее искать цвет по-другому.

Для этого существует цветовая модель HSV.

Она состоит из трёх частей:

    H --- Hue (тон): какой это цвет --- красный, жёлтый, зелёный,

синий?

    S --- Saturation (насыщенность): насколько цвет яркий и

насыщенный, а не сероватый?

    V --- Value (яркость): насколько светлый или тёмный цвет?

Представь, что ты выбираешь краску:

    H --- выбираешь цвет краски;
    S --- решаешь, будет ли он сочным или бледным;
    V --- выбираешь, будет краска светлой или тёмной.

В OpenCV значение H обычно находится в диапазоне от 0 до 179, а S и V
--- от 0 до 255.
Почему OpenCV для Hue использует 0–179?

Потому что OpenCV экономит память и использует для обычного изображения HSV формат uint8 — целые числа от 0 до 255.

uint8 - требует 1 байта данных, но может хранить не больше чем 255. Чтобы хранить угол от 0 до 360, можно было бы использовать отдельный тип данных. Но OpenCV выбрал более компактное представление: делит угол пополам.
Настоящий угол	Значение H в OpenCV
0°	0
60°	30
120°	60
180°	90
240°	120
300°	150
358°	179

То есть: HOpenCV=Hdegrees2

Поэтому вместо диапазона 0–360 мы получаем диапазон 0–179.

Запомни: HSV часто удобнее для поиска предметов по цвету, потому что
цвет отделён от яркости.
Переводим фотографию в HSV

hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

Теперь у нас есть версия фотографии, в которой можно выбирать нужный
цвет по диапазону HSV.
7. Маска --- волшебный трафарет

Компьютер --- детектив. Он ищет красное яблоко среди других предметов.

Но компьютер пока не понимает, что такое яблоко. Зато мы можем сказать
ему: «Ищи пиксели, цвет которых похож на красный».

Для этого создадим маску. Маска --- это чёрно-белая картинка:

    белый (255) --- пиксель подходит под наши условия;
    чёрный (0) --- пиксель не подходит.

Метафора: маска --- волшебный трафарет. Через него видны только те
места, которые мы разрешили искать.
Создаём маску с помощью inRange

hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

lower = np.array([35, 80, 50])
upper = np.array([85, 255, 255])

mask = cv2.inRange(hsv, lower, upper)

cv2.imshow("Mask", mask)
cv2.waitKey(0)
cv2.destroyAllWindows()

В этом примере мы задали примерный диапазон зелёных оттенков. Он может
потребовать настройки под конкретную фотографию и освещение.

cv2.inRange() проверяет каждый пиксель:

    если все три значения HSV попали в заданные границы --- пиксель

становится белым;

    если хотя бы одно значение не подходит --- пиксель становится

чёрным.

lower --- нижняя граница диапазона, upper --- верхняя.
8. Как увидеть только выбранную область?

Маска показывает, где находится нужный цвет. Но можно применить её к
исходной фотографии.

result = cv2.bitwise_and(image, image, mask=mask)

cv2.imshow("Selected object", result)
cv2.waitKey(0)
cv2.destroyAllWindows()

Теперь видны только те части фотографии, которые прошли через наш
«трафарет».
12. Самостоятельное задание: создай свой HSV-фильтр!
Миссия «Супердетектив»

Твоя задача --- создать программу, которая умеет находить на фотографии
предметы выбранного тобой цвета.

Можно искать:

    красные яблоки;
    жёлтые бананы;
    синие ручки;
    зелёные листья;
    оранжевые мячи.

Главное правило: ты сам выбираешь цвет и самостоятельно подбираешь
диапазон HSV.
Шаг 1. Выбери объект

Найди фотографию, на которой есть предмет нужного цвета.
Например, красная игрушка на столе.
Желательно, чтобы фон отличался от цвета предмета.
Шаг 2. Открой фотографию

Используй:

image = cv2.imread("my_photo.jpg")

Проверь, что изображение успешно загрузилось.
Шаг 3. Переведи изображение в HSV

hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

Шаг 4. Создай свой фильтр

Для начала попробуй такой диапазон для зелёного:

lower = np.array([35, 80, 50])
upper = np.array([85, 255, 255])

mask = cv2.inRange(hsv, lower, upper)

Но это только пример! Для другого цвета нужны другие значения.
Меняй числа и наблюдай, как меняется маска.
Шаг 5. Покажи результат

cv2.imshow("Original", image)
cv2.imshow("My mask", mask)
cv2.imshow("My filter", result)

cv2.waitKey(0)
cv2.destroyAllWindows()

Уровень «Профи»: настройка фильтра ползунками

Настоящий детектив не хочет каждый раз переписывать программу. Он хочет
менять настройки прямо во время работы!

OpenCV умеет создавать ползунки --- Trackbar.

import cv2
import numpy as np

image = cv2.imread("my_photo.jpg")

if image is None:
    print("Не удалось открыть фотографию")
    raise SystemExit

hsv = cv2.cvtColor(image, cv2.COLOR_BGR2HSV)

def nothing(value):
    pass

cv2.namedWindow("Settings")

# Ползунки нижней границы
cv2.createTrackbar("H min", "Settings", 35, 179, nothing)
cv2.createTrackbar("S min", "Settings", 80, 255, nothing)
cv2.createTrackbar("V min", "Settings", 50, 255, nothing)

# Ползунки верхней границы
cv2.createTrackbar("H max", "Settings", 85, 179, nothing)
cv2.createTrackbar("S max", "Settings", 255, 255, nothing)
cv2.createTrackbar("V max", "Settings", 255, 255, nothing)

while True:
    h_min = cv2.getTrackbarPos("H min", "Settings")
    s_min = cv2.getTrackbarPos("S min", "Settings")
    v_min = cv2.getTrackbarPos("V min", "Settings")

    h_max = cv2.getTrackbarPos("H max", "Settings")
    s_max = cv2.getTrackbarPos("S max", "Settings")
    v_max = cv2.getTrackbarPos("V max", "Settings")

    lower = np.array([h_min, s_min, v_min])
    upper = np.array([h_max, s_max, v_max])

    mask = cv2.inRange(hsv, lower, upper)
    result = cv2.bitewise_and(image, image, mask=mask)

    cv2.imshow("Mask", mask)
    cv2.imshow("Result", result)

    # Нажми ESC, чтобы закончить работу
    if cv2.waitKey(30) & 0xFF == 27:
        break

cv2.destroyAllWindows()

Подсказка: сначала настрой H, чтобы выбрать оттенок. Затем меняй S и
V, чтобы отсеять слишком бледные или слишком тёмные участки.

Дополнительное задание: Сделайте так, чтобы на изображении можно было выбрать два диапозона цветов. В таком случае понадобятся две маски и их объединение через
cv2.bitwise_or().
