### ⚙️ Шаг 1: Установка Python

Для работы с `djitellopy` требуется Python версии 3.6 или выше. Рекомендуется использовать актуальные версии (3.10–3.12), так как они обладают наилучшей совместимостью с библиотеками.

**🪟 Windows**
1.  Перейдите на официальный сайт [python.org](https://www.python.org/downloads/) и скачайте установщик (версию 3.12).
2.  При установке обязательно отметьте галочкой пункт **«Add Python to PATH»** (Добавить Python в PATH) — это критически важно для работы из командной строки.
3.  После завершения установки откройте командную строку (`cmd`) и проверьте версию:
    ```bash
    python --version
    ```

**🐧 Linux (Ubuntu/Debian)**
В большинстве дистрибутивов Linux Python уже установлен. Проверьте его наличие:
```bash
python3 --version
```
Если версия устарела или Python отсутствует, установите его через менеджер пакетов (пример для Ubuntu):
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
```

### 📦 Шаг 2: Создание виртуального окружения и установка библиотек

Использование виртуального окружения — лучшая практика, которая позволяет изолировать зависимости вашего проекта от системных пакетов.

**🪟 Windows**
```bash
python -m venv venv
venv\Scripts\activate
```

**🐧 Linux**
```bash
python3 -m venv venv
source venv/bin/activate
```
После активации в начале строки терминала появится `(venv)`.

**🐧 Linux** и **🪟 Windows**
Теперь установите необходимые библиотеки. `djitellopy` — для управления дроном, а `opencv-python` — для работы с видеопотоком.
```bash
python -m pip install --upgrade pip setuptools wheel
pip install djitellopy opencv-python
```
> **Примечание для Linux:** Если в вашей системе Python 3 не является версией по умолчанию, используйте команду `pip3 install ...` вместо `pip install ...`.


```python
from djitellopy import Tello

# Создаём объект дрона
tello = Tello()

# Подключаемся к дрону
tello.connect()

# Получаем уровень заряда батареи
battery = tello.get_battery()
print(f"Заряд батареи Tello: {battery}%")

# Завераем соединение
tello.end()
```

Официальная документация библиотеки `djitellopy` доступна по адресу [djitellopy.readthedocs.io](https://djitellopy.readthedocs.io/en/latest/).
