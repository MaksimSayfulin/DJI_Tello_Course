# DJI_Tello_Course

## Источники
* https://stepik.org/course/118876/promo
* DJI Tello python documentation: https://djitellopy.readthedocs.io/en/latest/tello/


## Структура курса
* Безопасность, устройство дрона, разбор регламента турнира. Подключение по Python, первая команда takeoff/land
* Базовые манёвры, относительная система координат. Повороты и облёт препятствий
* Телеметрия: батарея, высота, ToF. Безопасные сценарии и обработка ошибок
* Видеопоток + OpenCV: цветовое распознавание. Видеопоток + OpenCV: цветовое распознавание
* Коррекция курса по смещению маркера в кадре. Mission Pad: основы
* Mission Pad: навигация по нескольким меткам. "Архитектура: state machine"
* Простая обратная связь (центрирование по камере). Сборка комплексной трассы (объединение всех манёвров)
* Сборка комплексной трассы (объединение всех манёвров). Разбор полётов: анализ логов, типичные ошибки
* Стратегия: разбор незнакомого регламента, декомпозиция трассы. Тренировочный «турнир» внутри группы
* Доработка по итогам тренировочного турнира. Сертификационный полёт
